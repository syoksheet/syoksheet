Components / Select

Select

A select picks one value from a list too long for a segmented control. Native by default; a custom popover only when options need search, icons, or rich rows.

Beta2 kinds

Native select

The default. Matches input height and border, with a chevron affordance. Use it for plain text options — re-check cadence, category, sort.

Do & don't

Do

Default the most common value. Keep labels short; order logically (frequency, then alphabetical).

Don't

Don't use a select for 2–3 options (use segmented), or for actions (use a menu).

Accessibility

  • Native select is a real <select> with an associated <label>.
  • Custom dropdown uses role="listbox"/option, full keyboard support (↑↓, type-ahead, Esc), and returns focus to the button on close.
  • The trigger exposes aria-expanded and the current value as its accessible name.
  • Focus ring matches inputs; selected option is marked with aria-selected, not colour alone.
