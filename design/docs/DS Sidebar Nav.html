Components / Sidebar nav

Sidebar nav

The primary navigation for the whole app. One fixed rail, identical on every signed-in page, that groups destinations and nests each organisation's sections. It's the backbone of the product's information architecture.

Beta shared component

Anatomy

Brand lockup at the top, then labelled groups of nav items, an account card pinned at the bottom. Items have an icon + label, an optional trailing count, and one active item per page.

Organisation nesting

Each org is an expandable row. Open one and its sections appear, indented; one org is open at a time. A nested Brags group holds Verification and Moderation a level deeper. Sections shown depend on the member's role.

Do & don't

Do

Keep exactly one active item per page, matching the breadcrumb. Use counts only where a number is actionable.

Don't

Don't expand multiple orgs at once, nest deeper than two levels, or duplicate a destination across groups.

Accessibility

  • Rail is a <nav aria-label="Primary">; the active item carries aria-current="page".
  • Org rows are real <button>s with aria-expanded reflecting open/closed.
  • Active state is conveyed by fill and weight, not colour alone.
  • Fully keyboard-navigable; counts that mean "alerts" include visually-hidden text ("2 pending").
