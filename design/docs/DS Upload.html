Components / File upload

File upload

A dropzone plus a list of uploaded files. Used for brag attachments (PDFs, images, certs) and the avatar uploader. Supports drag-and-drop and a click-to-browse fallback, with per-file progress and removal.

Betadrag · browse

Anatomy

A dashed dropzone names the accepted types and size limit; below it, each file appears as a row with a type icon, name, meta, and a remove control. Uploading files show an inline progress bar.

Always validate on drop and on browse. State the accepted types and size limit up front, and reject with a clear clay error rather than failing silently.

Variants

  • Multi-file dropzone — brag attachments; stacks a file list below.
  • Single-image / avatar — a circular target that previews the cropped result; replaces rather than appends.
  • Inline add — a compact "browse" button when a full dropzone is too heavy.

Do & don't

Do

Show accepted types + size, per-file progress, and a remove on every file.

Don't

Don't rely on drag-and-drop alone — always offer click-to-browse, and never hide upload errors.

Accessibility

  • The dropzone wraps a real <input type="file">, so it's keyboard- and screen-reader-operable without drag.
  • Accepted types and limit are in visible text, not just the accept attribute.
  • Each file row's remove button has an aria-label naming the file.
  • Upload progress uses a progressbar role; completion and errors are announced via a live region.
