Progress & meter

Slim bars that show completion. A meter shows a static measured value (usage against a limit); a progress bar shows an ongoing task (upload, processing). Same bar, different meaning.

Betabar · ring · spinner

Meter

A measured value against a maximum — billing usage, quota. Pair with a label and a mono value. The fill warms to amber as it nears the limit, clay when full.

Meter vs. progress

NeedUse
A measured amount vs. a limit (usage)Meter
A task underway with a known %Determinate progress bar
A task with unknown durationSpinner / ring (indeterminate)
A whole page or section loadingSkeleton
A meter is teal until it's near the limit. Amber/clay are the only places these warm hues appear on a bar, and they always mean "approaching/at the cap" — never decoration.

Do & don't

Do

Pair a meter with its exact value in mono. Use indeterminate spinners only when the total is genuinely unknown.

Don't

Don't animate a fake progress bar, or use a full-screen spinner where a skeleton would keep layout context.

Accessibility

  • Meters use role="meter"; progress bars use role="progressbar" with aria-valuenow/min/max.
  • The value is always available as text (the mono label), not implied by bar width alone.
  • Indeterminate spinners set aria-busy on the region and have an accessible label ("Uploading").
  • Animation respects prefers-reduced-motion — the spinner reduces to a static state.
