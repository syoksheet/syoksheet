Spacing & layout

An 8px-based scale governs every gap, pad and margin. Spacing is applied with flex/grid gap, never ad-hoc margins between siblings — so layouts stay even and survive edits.

Beta 8px base

Spacing scale

Steps are multiples of 8px, with 4px half-steps for tight UI. Pick a token; don't type arbitrary pixel values.

Always space with gap. Use flex/grid gap for rows and groups — not bare margins on siblings. Gap spacing is explicit and survives drag-reorder, delete, and duplicate cleanly.

Corner radius

Four radii. Small for chips/inputs-in-groups, base for buttons/inputs, large for cards, xl for hero panels and modals.

App layout

Every signed-in page is a fixed sidebar rail plus a centred content column. Content maxes at 760px for reading pages, up to 1080px for dense, multi-column views.

252px sidebar · centred content · 40px page gutters.
  • Sidebar 252px, collapses to a 64px icon rail below 980px.
  • Content column centred; 760px for forms/reading, 1080px for tables/grids.
  • Page gutters 40px desktop, 20–22px on small screens.
  • Cards stack with 16px gap; section headers get 44–88px above.

Rules

  • Snap to the scale. If a value isn't on the 4/8 grid, round it until it is.
  • Consistency over precision. Reuse the same padding across sibling cards rather than fine-tuning each.
  • Whitespace is the premium signal — when in doubt, add a step rather than crowd.
  • Don't nest shadows. A raised card inside a raised card flattens the hierarchy; pick one.
