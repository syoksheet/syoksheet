Components / Toggle & switch

Toggle & switch

A switch turns a single setting on or off, taking effect immediately. Use it for binary preferences — notifications, 2FA, visibility — never for actions that need a separate Save.

Beta2 sizes

Anatomy & states

A pill track with a sliding thumb. Off is neutral grey; on fills with brand teal (or forest where the setting is a verification preference). State change is instant.

Switch vs. checkbox

Switch = takes effect now. Checkbox = part of a form you submit. If flipping it changes something immediately, it's a switch. If it's a choice you confirm later with Save, it's a checkbox.

Do & don't

Do

Use for instant on/off preferences. Pair with a clear label that reads true when on.

Don't

Don't put a switch in a form with a Save button, or use it for a destructive action without confirmation.

Accessibility

  • Built on a real <input type="checkbox"> with role="switch" and aria-checked.
  • The whole row is a <label>, so the label text is a click/tap target.
  • On/off is conveyed by thumb position, not colour alone; focus ring is always visible on keyboard.
  • State change is announced; an immediate side effect (e.g. signing out sessions) is described in the label or a following toast.
