Data table

The data table extends the basic table with the machinery for working with many rows: search, column sort, row selection with bulk actions, and pagination. Use it for the Members and Invoices views.

Features

FeatureBehaviour
SearchFilters rows live; sits left in the toolbar.
Column filtersDropdown chips in the toolbar (Role, Status…).
SortClick a sortable header; chevron shows direction. One sort column at a time.
SelectionPer-row checkbox + header select-all. Selected rows tint teal.
Bulk actionsA teal bar appears above the header with the count and actions.
PaginationFooter: "1–N of total" + page buttons. 25/page default.

Selection & bulk actions

  • Selecting rows reveals the bulk bar; it replaces nothing — it sits between toolbar and header.
  • Select-all in the header checkbox selects the current page; offer "select all 47" as a follow-up link when partial.
  • Destructive bulk actions (Remove) use clay styling and still confirm before running.
  • Clear selection is always one click away (uncheck the header box).

When to use which table

NeedUse
A short, read-mostly list (sessions, 3–6 rows)Table
Many rows needing search / sort / select / pagesData table
Rich items acted on individually (brags)Card list
Don't reach for the data table by default. Its machinery only earns its place past ~15 rows or when bulk operations are real. Below that, a plain Table is calmer.

Do & don't

Do
Selected rows tint teal; the bulk bar shows the exact count and a clear way to act or cancel.

Selection state is obvious and reversible.

Don't
Hiding bulk actions in a per-row ⋯ menu when many rows need the same operation.

Forcing row-by-row work when bulk is the real task.

Accessibility

  • Sortable headers are <button> with aria-sort="ascending|descending|none".
  • Row checkboxes have labels naming the row; the header checkbox is labelled "Select all on this page".
  • The bulk bar is an aria-live region announcing "2 selected".
  • Pagination buttons have labels ("Page 2", "Next page") and a disabled state at the ends.
  • Keyboard: Tab through controls, Space toggles a checkbox, Enter activates sort.
