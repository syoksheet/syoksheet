Components / Empty state

Empty state

An empty state stands in for content that isn't there yet — a fresh account, a cleared queue, no search results. It's an opportunity to orient and point to the next step, never a dead end.

Beta 3 kinds

Anatomy

A dashed container holds a single icon, a short title, one line of guidance, and one primary action. Centered, calm, never more than one CTA.

Kinds

Three situations produce an empty state. Each has a different tone — encouraging, reassuring, or corrective.

KindWhenTone & CTA
First-useNothing created yet (no brags, no orgs)Encouraging — primary "create" CTA

Placement

  • Fills the content region it replaces — inside the card, table, or page body, keeping any header/toolbar above it.
  • Dashed border distinguishes "nothing here yet" from a real, solid-bordered card of content.
  • Compact variant for small regions (a panel, a tab); full variant for a whole page.

Do & don't

Do

One icon, one title, one line, one action. Point clearly at the single next step.

Don't

Don't stack multiple CTAs, long paragraphs, or decorative illustration. An empty state isn't a marketing moment.

Content

  • Title names the absence plainly — "No brags yet", "You're all caught up".
  • One line of guidance on what to do or what will appear here.
  • CTA verb-first and matched to the kind: create (first-use), clear (no-results), none (all-clear).
  • Reassure, don't apologize. Empty is normal, not an error.

Accessibility

  • The icon is decorative (aria-hidden); the title carries the meaning as a real heading.
  • "No results" after a live search uses role="status" so the change is announced.
  • The CTA follows all Button accessibility rules.
