Typography

Two typefaces do all the work. Geist, a contemporary grotesk, carries every heading and UI label; Geist Mono marks "the record" — IDs, timestamps, counts, and index labels. The pairing is the type-level signature.

One sans for everything visible, one mono for machine-ish data. No serif, no third family.

Type scale

A short, purposeful scale. Display and H1 anchor pages; body and small carry reading; mono is the record. Sizes step deliberately — don't invent in-between values.

Usage rules

  • Mono is for the record. IDs, timestamps, counts, domains, hashes, and group labels — anything machine-generated or precise. Never set body copy in mono.
  • Headings are tight. Negative tracking scales with size; large display text gets the most.
  • Sentence case everywhere except mono labels, which are UPPERCASE and tracked.
  • Body never below 14px; 13px is the floor for secondary captions only.
  • One display per view. Display size is for a page's single hero moment, not section headers.
The mono ↔ sans contrast is the brand. A timestamp in Geist Mono next to a Geist heading is what makes a screen read as a precise record, not a generic dashboard. Use it deliberately.

Accessibility

  • Minimum body size 14px; UI never relies on text below 11px even for mono labels.
  • Line length caps around 65–75 characters for body via a max-width on text blocks.
  • Headings use real heading elements in order (h1…h3) — size is never faked on a div for hierarchy that AT needs.
  • Line-height ≥ 1.5 for body to satisfy WCAG text-spacing.
