Implementation / PrimeNG mapping

PrimeNG mapping

syoksheet is built in Angular with PrimeNG v21. The spec pages define how things should look and behave; this page maps each one to a PrimeNG component and ships a theme preset that makes PrimeNG match syoksheet automatically.

BetaPrimeNG v21@primeng/themes

Setup

PrimeNG v21 uses a token-based theme. Register the syoksheet preset once at bootstrap and every component inherits the brand — teal primary, neutral surfaces, our radii and focus ring.

syoksheet-preset.ts
// app.config.ts import { providePrimeNG } from 'primeng/config'; import { SyokSheetPreset } from './syoksheet-preset'; providePrimeNG({ theme: { preset: SyokSheetPreset, options: { darkModeSelector: '.dark', cssLayer: false } } });

Load Geist + Geist Mono globally and set --p-font-family: 'Geist'. Mono is for IDs, timestamps and counts only.

Don't reuse primary for verification. Teal is action; forest is "verified". Apply .p-tag-verified (defined in global CSS, see the preset footer) so the two never blur.

What stays custom

Three pieces carry the syoksheet identity and have no PrimeNG counterpart — build them as small standalone Angular components styled with the theme's CSS variables.

  • Verification mark — the flat forest check + "Verified by …" badge. The brand's signature; keep it bespoke and consistent.
  • Empty state — dashed container, one icon / title / line / action. A layout pattern, not a PrimeNG widget.
  • Sidebar nav — p-panelmenu covers the accordion, but the org mini-logos, verified stamps, alert counts and role-gating are custom wrapping.

Implementation rules

  • Theme the preset, don't override per-component CSS. Adjust tokens in syoksheet-preset.ts so the whole library shifts together.
  • Severities are semantic. warn = pending, danger = destructive. Never pick a severity for visual variety.
  • Keep the density rules. PrimeNG defaults are roomier; our spacing tokens and "essentials first" disclosure still govern layout.
  • Dark mode ships in the preset (.dark selector) with the brighter teal — but the product currently runs light-only; enable when needed.
