rules
· The shell never scrolls horizontally. Nothing in it may set a fixed min-width wider than the viewport — put min-width:0 on the content column and on every flex child that holds text.
· The content column is the only element that flexes. The sidebar and the topbar action group are flex-shrink:0; they change by switching state at a breakpoint, not by squeezing.
· Text shrinks before controls: the breadcrumb truncates, then actions drop labels, then actions fold into ⋯. An action never gets clipped off-screen.
· Only one action stays labelled below 1120px — the page's primary. Everything else is icon + tooltip.
· The sidebar never collapses to a rail or a drawer. It steps between fixed widths (260 / 230 / 200 / 180px) at the breakpoints and is always flex-shrink:0.
· Horizontal scrolling is allowed only inside a bounded region — a wide data table's own wrapper — never on body.
